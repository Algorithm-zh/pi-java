# v0.4.0 发布说明

> 版本：0.4.0
> 日期：2026-11-07
> 状态：已发布（2026-11-07）；Git tag 与 GitHub Release 已创建

## 亮点

v0.4 把“决策回看”做完整：被放弃的分支可以并排对比，也可以在两条已走过的路之间
来回切换，对话上下文与工作区一起还原。同时，pi-java 明确回到它的本职——一个本地
单用户 coding agent，删掉了整个账号、租户与空间体系，打开即用。

## 新增能力

### 分叉对比（M23）

- 时间线的回溯节点新增“对比两条分支”，只读展示被放弃分支与当前分支的意图、运行、
  审批、验证、计划与文件改动；
- 新增 `GET /api/v1/sessions/{id}/comparison?rewind={entryId}`，按路径级差异输出
  `onlyAbandoned`、`onlyCurrent`、`both` 三组文件，并给出确定性中文摘要；
- 对比全程只读：不要求会话空闲，不写 entry，不访问磁盘，不调用模型；
- CLI 新增 `/timeline`、`/compare [序号]` 与 `/rewind <序号>`，回退前先预览、再确认。

### 去账号化（M24，破坏性变更）

- 删除账号、租户、空间成员、登录注册与令牌，删除 HTTP 鉴权过滤器、Web 登录页与
  “账号与空间”设置，CLI 不再需要租户上下文；
- V9 迁移合并历史空间中的同名工具策略，删除 `tenant_id` 与四张身份表；
  会话、entry、审批、模型档案、插件与附件全部保留；
- 安全边界改为网络边界：默认只监听回环地址，绑定其他地址必须显式设置
  `PI_ALLOW_REMOTE=true`；新增无依赖的 `GET /api/v1/health` 供容器与脚本探测；
- 审批决策者固定记为 `local`，过期与取消记为 `system`。

### 分支切回（M25）

- 回溯与切回节点都能“切回这条分支”：移动到另一条已知分支的叶子，追加切回简报，
  并还原那条分支的工作区；
- 新增 `POST /api/v1/sessions/{id}/resume`，请求
  `{branchEntryId, dryRun, note}`，返回两侧 entry/run 数、将改动的文件、冲突与简报；
- 切回后聊天区出现“切回简报”，时间线新增 `RESUME` 节点，支持双向往返；
- 对比对话框同时服务回溯与切回节点，文案统一为“另一条分支 / 当前分支”；
- CLI `/resume [序号]` 先 dry-run 预览，确认后执行；非交互终端拒绝切换。

### 修复 MySQL V9 迁移

- MySQL 8 中 `uk_tool_policy` 是外键 `fk_policy_tenant` 的支撑索引，
  原来的先删索引后删外键会报
  `Cannot drop index 'uk_tool_policy': needed in a foreign key constraint`；
- 现在先删除外键再删除索引，全新 MySQL 库可以顺序执行 V1–V9；
- H2 迁移文件保持不变，已升级过的本地库不会触发 Flyway 校验和不一致。

## 升级说明

- **数据库**：Flyway 自动执行 V9。升级前请备份 `${PI_DATA_DIR}`；V9 会删除
  `pi_app_user`、`pi_auth_token`、`pi_space_member`、`pi_tenant` 四张表，
  并把同名工具策略合并为一条，**不可逆**。
- **账号与登录**：v0.3 的 `/api/v1/auth/*`、`/api/v1/users/*`、
  `/api/v1/tenants/*` 接口已全部移除，旧的登录 Cookie 与 Bearer 令牌不再有意义。
  原先按空间隔离的数据会保留在库中，直接以单用户身份可见。
- **网络访问**：默认只监听 `127.0.0.1`。如果确实需要从其他机器访问，设置
  `PI_ALLOW_REMOTE=true` 并自行加网络隔离（端口可达即等于可以执行工具）。
- **健康检查**：容器与脚本请使用 `GET /api/v1/health`，
  原来的公开探测端点 `/api/v1/auth/state` 已不存在。
- **CLI**：`/timeline`、`/compare`、`/rewind`、`/resume` 均无需登录；
  审批在非交互环境仍默认拒绝。
- **产物命名**：`pi-java-app/target/pi-java-app-0.4.0.jar`；镜像示例为
  `pi-java:0.4.0`。

## 启动方式

本机：

```bash
mvn -q -DskipTests package
java -jar pi-java-app/target/pi-java-app-0.4.0.jar
```

脚本（自动探测 JDK 21，可选注入模型 Key）：

```powershell
.\scripts\start.ps1
```

Docker：

```bash
docker build -t pi-java:0.4.0 .
docker run --rm -p 127.0.0.1:8080:8080 \
  -v "$PWD:/workspace" -v pi-data:/app/data pi-java:0.4.0
```

Compose：

```bash
docker compose up --build
```

打开 <http://127.0.0.1:8080> 即可使用，无需注册或登录。更多环境变量、MySQL 变体
与安全说明见 [14 部署、容器与 CI](../14-deployment.md)。

## 已知限制

- 单 JVM、单实例：Run 注册表、SSE、审批等待与会话锁都在进程内，不支持横向扩展；
- 没有账号与鉴权，端口可达即可执行工具，远程访问必须自行加网络隔离；
- 分叉对比与分支切回只在同一会话内生效，不支持跨会话或 `fork` 子会话；
- 对比是路径级差异，不生成逐行 diff；
- 切回要求会话空闲，冲突一律整体放弃，不自动合并两条分支的改动；
- 回溯只支持运行开始前的检查点，不能回到单轮中间；
- 内部检查点 ref 长期积累，只随会话删除清理；
- 附件配额是全局总量，不支持 PDF、音频、视频，GIF 不压缩；
- `repo_map` 是关键词检索，不做语义向量与跨文件引用，也不提供 LSP 跳转；
- 镜像未发布到镜像仓库，没有多架构、SBOM 与签名。
