# M18：仓库地图与代码检索

> 日期：2026-10-28
> 状态：已完成；`mvn -q test` 861 个测试全绿，真实仓库索引冒烟通过，8080 实例未受影响
> 范围：文件级符号索引、关键词检索、`repo_map` 内置工具、提示词与 Web 工具目录展示

## 目标

M17 之后，模型已经能读文件、搜索正则、改代码，但进入一个陌生仓库时仍要先花很多轮
`ls`/`grep` 猜目录。M18 补上“先看地图、再精读”的能力：

- 不指定关键词时回答“这个仓库有什么”：语言分布、一层目录结构、关键文件；
- 指定任务关键词时回答“该先看哪几个文件”：文件排名、主要符号、命中行；
- 只用 JDK，不引入 LSP、AST、向量数据库或外部索引服务；
- 索引与检索都不执行工作区代码，文件规模与输出长度都有硬上限。

## 交付范围

- 基础设施 `com.piagent.infrastructure.tool.index`：
  - `CodeTokenizer`：驼峰/下划线拆分、中文二元组、英文与少量中文停用词；
  - `SourceSymbols`：按行提取 Java/Kotlin、Python、JS/TS、Go、Rust、SQL 与
    Markdown 标题，过滤 `if/for/return` 等语句；
  - `CodeIndexBuilder`：读取 UTF-8 文本、统计词频、提取符号与路径词；
  - `WorkspaceCodeIndex`：文件指纹扫描、LRU 快照缓存、BM25 风格排序与范围过滤；
  - `RepoMapFormatter`：把概览与检索结果压缩成模型可读的短文本；
  - `RepoMap`、`IndexSnapshot`、`IndexScope`、`FileHit`、`SourceSymbol` 等记录；
- 工具接入：
  - `RepoMapToolHandler`；`BuiltInToolCatalog` 新增 `repo_map`（LOW、PARALLEL、20s）；
  - `BuiltInToolHandlers` 注册执行体；参数为可选的 `query`、`path`、`maxFiles`；
- 提示词：身份规则改为“需要了解工作区时先用 `repo_map` 定位，再精读”；
- Web：`/tool` 菜单新增“仓库地图”与中文参数标签。

## 关键设计

- **零外部依赖**：分词、符号提取与排序全部是 JDK 代码。没有 LSP 进程、没有
  embedding，也不需要下载模型；离线可用，启动零等待。
- **先定位再精读**：概览只列一层目录与关键文件，检索每个文件最多四个符号、两行匹配。
  结果末尾明确提示改用 `read` 或 `grep`，避免把仓库地图当成完整内容。
- **排序有路径与符号加权**：内容词频使用 BM25（k1=1.2、b=0.75）；路径命中额外 ×2.5，
  符号名命中 ×3.5。改一个功能时，文件名和类名往往比正文注释更能指示位置。
- **增量索引**：每次调用只遍历并读取文件大小/修改时间；指纹不变就复用上次快照，
  变化才重建。缓存按工作区 LRU 保留最近 8 份，避免多会话逐个占内存。
- **中文按二元组**：不引入分词库；`审批流程` 会产生 `审批/批流/流程/审批流程`，
  同时命中“审批”和“审批流程”两种写法。停用词只去掉虚词，不删领域词。
- **符号宁缺毋滥**：只认行首声明与常见修饰符；同一行最多一个符号；Markdown `#` 标题
  只在 `.md/.markdown/.mdx` 中识别，避免把 YAML/Python 注释当成结构。
- **有界且可解释**：最多 5,000 个文件、深度 32、单文件 1 MB、总量 32 MB、每文件
  300k 字符与 2,000 个不同词，输出截断到 16k；跳过数与截断状态写进结果详情。
- **沙箱不变**：`path` 先经 `RealPathResolver`，越界返回 `PATH_OUTSIDE_WORKSPACE`；
  遍历沿用 `WorkspaceWalker`，跳过隐藏目录、`target/build/node_modules` 等，不跟随符号链接。

## 已知限制

- 不是语法分析：多行注解、泛型嵌套、匿名类或复杂宏可能漏报符号，但不会影响读取；
- 检索是关键词匹配，不做同义词扩展或语义向量；换一个词可能得到不同结果；
- 中文只有二元组，没有词性、分词与拼音；极短查询（单字）会被长度规则过滤；
- 索引只存在于进程内存，重启后首次调用重建；快照按大小 + 修改时间失效，
  同一毫秒内改回原大小的情况可能漏检；
- 忽略隐藏目录与常见构建目录，也不会读取 `.gitignore`；例如 `data/`、`promo-video/`
  若存在会被当作普通工作区内容索引；
- 只做文件级定位，不提供跨文件引用、调用链或 LSP 跳转；
- 超大仓库会触发 5,000 文件 / 32 MB 上限并在结果中标记截断。
