# M10：界面重构 · 信号工作台

> 日期：2026-10-23
> 状态：已完成；桌面 1440×900 与移动 531×553 浏览器实测通过
> 范围：只重做 Web UI 的视觉层与少量文案，不改后端契约与交互逻辑

## 目标

初版界面是暖米色 + 陶土色的圆角卡片组合，视觉上接近通用的 AI 聊天模板，
无法体现 pi-java “本地 coding agent 工作台”的定位。本里程碑从设计令牌开始重建界面：

- 建立可复用的颜色、字体、间距、阴影与焦点规范；
- 让会话列表、运行轨迹、工具结果、审批与设置中心形成统一层级；
- 保持零前端框架、零构建步骤，继续只使用 `textContent`；
- 桌面与移动端都能完成新建会话、审批、设置等核心操作；
- 字体本地化，离线启动不依赖 CDN。

## 视觉概念

关键词：**本地工作台、纸面、墨黑、信号色**。

界面像一张钉在墙上的工程图纸：冷灰纸面承载内容，墨黑负责结构与输入区，
信号黄只给主操作与当前状态，钴蓝只给焦点与信息，绿色/红色只表达成功与失败。
不使用装饰性渐变、柔和投影和悬浮圆角卡片；除弹窗外不出现阴影，
弹窗使用 6–8px 无模糊硬投影，强调“被放到桌面上的纸片”。

刻意避开的常见 AI 界面套路：

- 奶油色 + 陶土橙 + 衬线标题；
- 近黑背景 + 荧光绿终端风；
- 全大写小标题、密集圆点分隔、所有小字都用等宽字体；
- 大圆角白卡片 + 柔和阴影的 SaaS 组件库风格。

## 设计令牌

`css/theme.css` 是所有页面的唯一视觉入口：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ink` | `#101314` | 侧栏、输入区、深色井 |
| `--paper` | `#e8eae4` | 主区域冷灰纸面 |
| `--sheet` | `#f7f8f3` | 卡片与弹窗纸面 |
| `--rule` / `--rule-strong` | `#c9cdc5` / `#8e968f` | 分隔线与描边 |
| `--text` / `--muted` | `#121617` / `#5f6862` | 正文与次要信息 |
| `--yellow` | `#f4c400` | 主操作、当前会话、审批警示 |
| `--blue` | `#1f3bff` | 焦点环、信息、压缩记录 |
| `--green` / `--red` | `#116b50` / `#c3301c` | 成功/批准 与 失败/拒绝 |
| `--sans` | Archivo + 中文系统字体 | 界面正文 |
| `--mono` | IBM Plex Mono | 会话编号、路径、参数、用量 |
| `--shadow-hard` | `6px 6px 0 rgba(16,19,20,.14)` | 仅弹窗 |

字体使用本地 woff2：Archivo 400/600/700、IBM Plex Mono 400/500，
共 5 个文件约 75 KB，放在 `static/fonts/`，由 `theme.css` 声明 `@font-face`。
正文回退到 PingFang SC / Noto Sans SC / Microsoft YaHei，保证中文观感。

## 页面结构

### 外壳与会话列表

- 268px 墨黑侧栏；品牌区用黄底 π 标记，不使用图片；
- “新建会话”是侧栏唯一的高饱和黄色按钮；
- 会话条目改为“编号 + 标题 + 状态/工作区”的两行结构，编号使用等宽字体；
- 当前会话变成纸面卡片并带黄色方形标记；侧栏右缘保留稀疏刻度，暗示工作台标尺；
- 移动端侧栏折叠成顶部工具条，会话横向滚动，保留新建与设置入口。

### 欢迎页

欢迎页是一条命令索引：`01 /read README.md`、`02 /ls .`、`03 你好`，
每行包含编号、命令、说明与箭头，整行可点击。没有会话时卡片在视口内垂直居中；
空会话内只保留紧凑版本，避免大片留白把内容压到顶部。

### 对话与工具轨迹

- 用户消息是墨黑色块，左侧 3px 黄边，右上角标注“你”；
- assistant 消息左侧有一条垂直运行轨迹，消息与工具卡片都挂在轨迹上；
- 工具卡片由浅色标题行 + 深色输出井组成，状态用方形 LED + 文本，
  避免彩色圆点；错误状态改为红色方块；
- 压缩、模型切换、审批等历史条目是带彩色左条的备注条，
  审批记录使用绿色/红色左条与状态标签；
- 每轮结束有一行 `2 轮 / 1 个工具 / 30 tokens / 6.8 s / 完成` 的摘要。

### 输入区

输入区是深色控制台面板：浅色文字、黄色方形发送按钮、钴蓝焦点环。
模型名称以等宽字体显示在右侧；上方是紧凑的 run 用量条，
下方是 Enter / Shift+Enter 提示与 demo 工作目录。移动端隐藏模型名与提示，保留发送按钮。

### 弹窗与设置中心

- 新建/会话设置弹窗为纸面卡片，黑色 1px 描边 + 硬投影；
- 审批弹窗顶部使用黄黑警示条纹，工具与参数分成清晰区块：
  风险标签、工具名、剩余时间、脱敏参数、SHA-256 摘要、意见与决策按钮；
- 设置中心是 1000×740 的纸面面板，左侧 196px 墨黑标签栏，
  当前标签整行黄底；右侧内容区保持单列阅读宽度；
- 设置卡片、表单、密钥命令块、空状态与错误状态全部使用同一套描边和间距；
- 移动端设置中心铺满视口，标签栏改为横向滚动。

## 已知限制

- `:has()`、`dvh` 等现代 CSS 特性需要较新的 Chrome/Safari/Firefox；
- 本地字体约 75 KB，首次加载后由浏览器缓存，不依赖外网；
- 视觉层不引入鉴权或额外安全边界，v0.1 仍只监听回环地址；
- 前端继续禁止 `innerHTML`，所有模型/工具文本走 `textContent`。
