# M9：Web UI 完善与开源准备

> 日期：2026-10-23
> 状态：Web UI 与设置中心已完成；CLI 推迟到下一里程碑
> 提交：`feat(web): settings center, session settings and context meter`

## 目标

把 M4–M8 已经具备的能力全部暴露到 Web UI，让不写 curl 的用户也能完成：

- 新建、重命名、切换模型、归档会话；
- 看懂上下文用量，手动触发压缩；
- 配置模型档案与密钥环境变量；
- 浏览技能、安装/启停插件、编辑工具策略；
- 查看压缩、审批、模型切换等非消息类历史条目。

同时完成开源仓库需要的基本材料：README 截图、许可证、文档索引与忽略规则。

## 交付物

### 后端补充

| 类型 | 说明 |
|---|---|
| `SessionSettingsApplicationService` | 重命名、切换模型/思考级别、归档；只更新会话元数据 |
| `SessionSettingsController` | `PATCH /sessions/{id}`、`PUT /sessions/{id}/model`、`POST /sessions/{id}/archive` |
| `ContextStatusView` / `ContextStatusResponse` | `GET /sessions/{id}/context` 的只读上下文估算 |
| `CompactionController` | 在手动压缩之外增加上下文状态查询 |
| `ApiKeyStatus` / `ModelProfileResponse.apiKeyConfigured` | 只返回环境变量是否存在，不读取或回传密钥 |

约束：

- 切换模型要求目标档案存在且启用，且会话必须是 `IDLE`；
- 归档只允许 `IDLE`，归档后发送、压缩、切换模型全部被拒绝；
- 重命名不限制状态，归档会话仍可改名；
- 上下文接口不写 entry、不触发压缩。

## 实际运行

```bash
mvn -q -DskipTests package
java -jar pi-java-app/target/pi-java-app-0.1.0-SNAPSHOT.jar
```

打开 <http://127.0.0.1:8080>，默认 Fake 模型即可完成上述流程。

## 已知限制

- **CLI 尚未实现**：`pi chat/run/sessions/...` 仍是规划契约；
- **fork / branch 未暴露 HTTP**：应用层已有用例，前端暂无入口；
- **健康检查未实现**：`GET /health` 仍在计划中；
- **策略没有删除接口**：设置页只能覆盖已有规则；
- **插件只接受本地 jar 路径**：没有上传接口；
- **设置中心没有权限模型**：v0.1 无鉴权，依赖 loopback 绑定；
- **归档不可恢复**：领域层暂未提供 unarchive。
